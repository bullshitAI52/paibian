# 上海过渡生存完整指南

> 适用场景：手头钱不多、没保安证，想在上海找份包吃住的工作过渡，稳定下来后再图发展。

---

## 一、整体路线图：三个阶段

```
第一阶段（第1-7天）：到上海 → 落脚 → 找到工作
    核心目标：尽快入职包吃住岗位
    预算：建议至少准备 1000-1200 元

第二阶段（第1-2个月）：稳定工作，攒钱
    核心目标：工作的同时摸清上海门路，存下一笔现金
    月收支：包吃住下月支出 ≈ 200-500 元，月结余 3000-5000 元

第三阶段（第3个月起）：决定下一步
    方向A：继续现有工作，边做边学（适合空闲多的岗位）
    方向B：用攒下的钱换到技术岗/更好的工作
```

### ① 物业保安

**推荐理由：** 需求量大、稳定、夜班空闲多可以看书学习。

| 类型 | 月薪 | 包吃住 | 特点 |
|---|---|---|---|
| 写字楼保安 | 4000-5500 | ✅ 大多包 | 站岗+巡逻，环境好 |
| 小区物业保安 | 3500-5000 | ✅ 基本都包 | 门岗为主，夜班空闲多 |
| 商场保安 | 4000-5500 | ⚠️ 部分包 | 巡逻+客流引导 |
| 医院/学校保安 | 3800-5000 | ✅ 大多包 | 稳定，要求略严 |

**渠道：** BOSS直聘搜"保安 包吃住" → 万科物业/绿城/碧桂园等大公司公众号 → 直接去小区物业问

**保安证说明：** 上海正规岗位可能需要保安证。很多公司可以**先上班后考证**，公司统一安排，费用从工资里扣或公司出。如果面试时问"你没保安证，我们可以安排你去考"，那就没问题；一上来就让你自己去交钱考的，要谨慎。

## 五、找工作渠道（按优先级排名）

### 第一：BOSS直聘（效率最高）

上海蓝领招聘最主流的 App，占这类岗位约 **60%** 的招聘量。

- **怎么搜：** 搜 `保安 包吃住` / `酒店 包吃住` / `服务员 包吃住`
- **筛选：** 勾上"包吃"和"包住"
- **看什么：** 优先"公司直招"标签
- **怎么聊：** 直接发消息问——"请问宿舍在公司附近吗？几人间？试工期有工资吗？"
- ✅ **到上海前就聊好，到了直接安排面试**

### 第二：58同城（岗位最多，但骗子也多）

- **怎么搜：** 同样关键词，筛选"企业认证"和"营业执照已认证"
- ❌ **跳过**所有"跟单员""押运员""高薪保底""当天安排住宿"
- ❌ 任何要先交钱的都是诈骗

### 第三：线下上门问（信息差最大，竞争最少）

很多小店小物业公司**不挂网**，门口贴张纸就招人。这种反而最靠谱——直接和店长聊，谈好了当天住进去。

- 到了目标区域，打开地图搜附近的"酒店""火锅""商场""物业"
- 一家一家进去问："请问还招人吗？包吃住吗？"
- **尤其是刚开业/正在装修的店**，肯定大量招人

### 第四：品牌官方公众号（最稳妥）

| 方向 | 搜什么 |
|---|---|
| 餐饮 | "海底捞招聘" "老乡鸡招聘" |
| 酒店 | "华住微招聘" "锦江招聘" |
| 物业 | "万科物业招聘" "碧桂园服务招聘" |
| 物流 | "京东招聘" "顺丰招聘" |

### 第五：日结渠道（刚到上海快速回血）

找不到正式工作前，先做几天日结有现金流：

| 工作 | 日薪 | 渠道 |
|---|---|---|
| 展会安保/活动保安 | 150-200/天 | 微信搜"上海日结"群 |
| 快递分拣夜班 | 180-250/晚 | 直接去物流园门口 |
| 酒店宴会帮工 | 150-200/天 | 58同城日结标签 |
| 搬家装卸 | 200-300/天 | 58同城日结 |

> 日结只是**过渡手段**，目的是给你一两周时间去找正式包吃住岗位。

| 吃饭 | 0-300 元 | ✅ 公司包吃的话=0；部分公司只包工作日 |
| 日用品 | 50-100 元 | 卫生纸、洗衣液等 |

| 其他（理发等） | 50-100 元 | |
| **总计** | **200-500 元/月** | |

**月结余：**

```
保安/酒店类： 3500-4800（实发） - 500（支出） = 3000-4300 元/月
工厂普工类：  4500-6000（实发） - 500（支出） = 4000-5500 元/月
```

**做3个月能攒下：约 9000-16000 元**

这笔钱足够你：
- 辞掉包吃住工作，自己租房换更好的工作（押一付三约 3000-6000 元）
- 或者报个技能培训班
- 或者学驾照/考电工证/保安证
- 或者就纯粹存起来了

## 七、省钱技巧

- **社区食堂：** 微信搜"上海社区长者食堂"，15块两荤一素，对年轻人开放
- **公共图书馆：** 上海图书馆、各区图书馆免费开放，有WiFi有空调，休息日好去处
- **交通折扣：** 上海地铁每月消费满一定额度后打9折；公交2元
- **洗澡：** 如果宿舍没热水，可以去大众点评找15-20块的澡堂/汗蒸
- **就医：** 上海有社区卫生服务中心，挂号10-20块，小病去那看
- **免费培训：** 关注"上海工会"公众号，偶尔有免费职业技能培训（电工/保安证等）
- **政府补贴培训：** 部分区人社局有补贴项目，学电工/计算机等几乎免费

## 八、防骗核心原则

> **任何要你先交钱的工作 = 骗子。**

### 常见骗局

| 骗局类型 | 话术 | 真相 |
|---|---|---|
| "先交服装费/押金" | 入职前要交380办工服 | 正规公司从不收 |
| "高薪急聘" | 月薪过万还包吃住 | 天上不掉馅饼 |
| "跟单员/押运员" | 月入8000+轻松岗 | 经典58骗局 |
| "先交钱办保安证" | 办证需要380元 | 公司安排的事，不需要你个人先交 |
| "面试点交费后安排工作" | 加微信发定位到一个地方 | 到了就让你交钱 |

### 正规公司的流程

```
面试 → 谈待遇 → 看宿舍 → 签合同 → 入职上班
```

面试当天不签合同、不安排看宿舍、直接让你交钱的——**转身就走。**

## 九、从过渡到技术岗的路线图

> 如果你会写代码，包吃住只是过渡，你的最终目标是在上海做技术工作。

```
第1-2个月：包吃住岗位稳住现金流
    ↓ 优先选空闲多的：夜班保安 / 夜班前台 / 宿管
第3-4个月：用空闲时间保持写代码/做项目
    ↓ 在BOSS上投初级前端/技术支持/IT运维（上海6k-9k）
第5-6个月：换到技术岗，自己租房，经济真正独立
```

### 最适合边打工边学编程的包吃住岗位排名

1. **大学宿管** — 空闲最多，有校园WiFi
2. **酒店夜班前台** — 晚上基本没事，可以写代码
3. **夜班保安（写字楼）** — 巡逻完就坐着
4. **停车场值班** — 看监控，非常轻松
