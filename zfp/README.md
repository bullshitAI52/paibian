# ZFP 排班页面

对应线上 https://www.shuanghai.shop/zfp/ 。此目录保留该部署版本，仓库根目录首页是另一部署版本，不混合覆盖。

## 2026-09-29 修复

- 指定日期勾选“优先”后，白夜班人数覆盖普通每天8–9人限制。
- 支持1、2日白夜班各5人，3、4日白班5人、夜班4人。
- 2+2模式保留已填休息，空白人员按两次连休安排；已固定的休息可作为例外，其余优先补成连休，每人共4休。
- 搜索会同时检查班组人数、每日总人数和固定日期，失败时保留原表。
- 已有本机存档时，刷新不再自动重新排班。

## 验证

在仓库根目录执行：

```bash
node zfp/tests/staffing.cjs
node zfp/tests/fixed-rest.cjs
```

测试覆盖三种模式、国庆指定人数、固定休息保留（含三天连休）、每人4休和冲突不改原表。采用匿名人员数据，不包含用户浏览器存档。

## 部署

页面使用相对路径 `js/vue.global.js` 与 `js/xlsx.full.min.js`，本目录以 `js` 符号链接复用仓库根目录的库。部署到已有站点时保留线上 `zfp/js/`，仅替换 `zfp/index.html`，替换前备份。页面状态存于浏览器 localStorage，更新源码不会上传个人存档。
